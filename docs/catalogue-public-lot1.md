# Catalogue public — données de présentation (lot 1)

Prépare les données affichées par la refonte du catalogue et de la fiche
formation ([J16](j16-general-public-catalogue.md)). Les pages elles-mêmes
viendront aux lots suivants.

## Décisions

| Sujet | Règle |
| --- | --- |
| Niveau, certification | Champs explicites de la fiche formation (onglet **Site web**), indépendants des étiquettes eLearning. |
| Nouveau | Date de première publication posée une seule fois, automatiquement. Badge pendant le nombre de mois défini sur la société (6 par défaut, 0 le désactive). |
| Points forts, FAQ, formations associées | Saisis sur la fiche ; publiés seulement avec la présentation générale. Seules les formations associées publiées par la même société sont projetées. |
| Tarif inter | Un seul produit « Tarif inter-entreprises public » par formation : service vendable par personne. Montant affiché hors taxes, dans la devise du produit. Intra : toujours sur devis. |
| Lieu public | Champ de la réalisation (ville, « Classe virtuelle »). Les lieux des séances restent privés. |
| Places restantes | Calculées comme les disponibilités S03 ; signalées sous le seuil de la société (3 par défaut, 0 le désactive). Capacité nulle : aucun décompte. |
| Prochaine session | Première session publique, ouverte, future et non complète d'une version publiée. |
| Programme | Affiché en entier depuis la fiche formation ; le PDF de programme reste privé (cadrage du 3 novembre). |

Le tarif et les durées de l'offre autonome relèvent du dépôt eLearning.

## Recette courte

1. Publier une formation, la retirer puis la republier : la date de première
   publication ne change pas ; le badge disparaît après la durée configurée.
2. Saisir niveau, certification, quatre points forts, deux questions et une
   formation associée non publiée : seuls trois points forts, les deux questions
   dans l'ordre et aucune formation non publiée sont projetés.
3. Marquer un tarif par personne comme public : un second est refusé, un tarif
   forfaitaire aussi ; le montant projeté est hors taxes.
4. Publier une session de 4 places avec un lieu public, réserver 2 places : lieu,
   « Plus que 2 place(s) » et prochaine session apparaissent.
