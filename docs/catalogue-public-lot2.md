# Catalogue public — page catalogue (lot 2)

Refonte de `/formations` à partir des données du [lot 1](catalogue-public-lot1.md).

## Décisions

| Sujet | Règle |
| --- | --- |
| Formats | Inter-entreprises : une session publique ouverte à venir. Intra-entreprise : une version avec formateur publiée (sur devis). En autonomie : une offre ou une version eLearning. Choix porté par `?format=`. |
| Filtres | Domaine (catégorie), niveau, durée (1 jour ou moins, 2 à 3, 4 et plus), certifiante, session dans les 3 mois, distanciel possible. Liens à compteurs, un choix par filtre, sans JavaScript. `mode` reste accepté. |
| Tri | Pertinence, prochaine session, prix (sans prix en dernier), durée, nouveautés. |
| Carte | Domaine, badge Nouveau, titre, présentation, durée, niveau, certifiante, « Avec formateur » et/ou « eLearning » (seule mention des formats, sans liste Inter / Intra / Autonomie ni lien vers les offres), étiquettes, prochaine session ou « Sur demande », prix HT (par participant pour l'inter) ou « Sur devis ». |
| Recherches fréquentes | Saisies sur la société (une par ligne, huit au plus). |
| Paramètres | Valeurs inconnues ignorées ; la recherche garde format et tri ; la pagination garde tous les choix. |

Le bloc « Décrire un projet sur mesure » (Ventes) est placé sous les filtres.

## Recette courte

1. Publier deux formations de durées et niveaux différents ; filtrer par niveau,
   durée et certifiante : les compteurs et les cartes suivent, chaque filtre se
   retire seul, « Tout effacer » revient au catalogue complet.
2. Choisir chaque format : seules les formations proposant ce format restent.
3. Trier par durée et par prix ; vérifier la pagination avec filtres.
4. Sur mobile, ouvrir « Filtrer » ; vérifier la lecture au clavier.
